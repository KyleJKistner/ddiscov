# Discovery crosswalk

Historical lookup tables from the October–November 2026 screens. Search by intervention, disease, platform or endpoint, then follow the identifier into the relevant record. Use [current opportunities](../decisions/current-shortlist.md) for priority.

| File | Unit and coverage |
|---|---|
| [Historical topics](historical-topics.csv) | 232 topic groups. |
| [Topic occurrences](topic-occurrences.csv) | 825 named entries, linked to original H numbers. |
| [Component proposals](component-proposals.csv) | 70 proposals representing 68 concepts. |
| [Functional comparisons](functional-comparisons.csv) | 67 records representing 57 concepts. |
| [Broad preclinical screen](broad-screen.csv) | 34 screening records. |

Identifiers support lookup. Related constructs, repeated mentions and distinct studies retain their own units. The source coordinates and citations identify the original scope; [mapping notes](reference.md) explain merges, omissions and counting conventions.

For curated biological comparisons, see the [program atlas](../atlas/README.md). For later evidence, use the [research guide](../research/README.md).
