## What a rank means

Their historical analyst ranges buy different milestones and are not current quotes. They cannot be added into a funded portfolio or treated as equivalent costs of proving clinical benefit.

The additional-screen ordering is a priority for bounded, consequential information if available at suitable terms. It is not a numerical asset-return ranking or an authorization to fund development. Closed source passes are not automatically demoted. The default alternative of retaining capital and waiting remains explicit.

## Reproducing publication checks

In a checkout containing the baseline commit, run:

```bash
python3 research/rounds/round24/verify_round24.py
```

The verifier reads files and Git history only. It checks preservation, intended changes, candidate/source consistency, local links and manifest hashes. It does not validate the biological hypotheses or calculate investment returns. The containing Git commit identifies the published content; the manifest's own digest is bound by that Git tree to avoid a recursive self-hash.
